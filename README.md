## Deploy to Vercel
### Option 1: Drag and drop
Upload the project folder to Vercel.

### Option 2: GitHub
1. Create a GitHub repository.
2. Upload these files.
3. Import the repository into Vercel.
4. Deploy.

## Custom domain
In Vercel:
Project → Settings → Domains → Add domain.

Suggested:
- shreenivasjoshi.com
- shreenivas.ai
- shreenivasjoshi.dev

## Important note about the AI Résumé Assistant
The current assistant is a lightweight client-side knowledge assistant grounded in the résumé facts included in the website. It does not call an external LLM API and therefore requires no API key or backend.

For a true production RAG version, add a backend/API layer and connect it to an LLM provider plus a vector database.
